## Description

**VERA Atelier** is a complete fashion store you can rebuild inside Elementor in an afternoon.
Every section is a paste-ready HTML widget that runs on one clean CSS design system and one small
vanilla-JS file — no page-builder add-ons, no shortcodes, no jQuery, no WooCommerce dependency.

**What makes it different**

- **Real category filtering.** Click *Women*, *Men*, *Shoes* — only that category's products are
  shown, the headline, breadcrumb, item count and the URL (`?cat=men`) all update, and the browser
  back button behaves.
- **Working cart.** Add / remove / quantity / total, persisted in `localStorage`, slide-in drawer,
  order email on checkout.
- **Verified responsive.** Tested at 320 / 360 / 390 / 414 / 768 / 1024 / 1440 px with **zero
  horizontal overflow**. Two-column grid on phones, app-style bottom tab bar, scrollable category
  chips.
- **Gentle palette.** Warm off-white paper, soft clay accent, Fraunces + Inter — white, calm and
  easy on the eyes, ready to re-skin from one <code>:root</code> block.
- **Works without JavaScript.** Content is never hidden unless JS is confirmed active, so a script
  error can never blank your page.

**What's in the package**

|---|---|
| Design system | `vera-kit.css` (commented, token-based) |

**Requirements**

- WordPress + Elementor 3.x (Free is enough — Pro only for Theme Builder / Custom Code)
- Any theme (Hello Elementor recommended)
- No WooCommerce, no paid add-ons

**Installation in one line:** upload `vera-kit.css` + `vera-kit.js` + `images/`, paste
`00-loader.html` once, then paste the section widgets you want.

**Licence:** code MIT (use it in client projects), photos CC0. Brand name, copy and prices are
placeholders you can replace with your own.

## FAQ (paste into the platform's FAQ field)

**Do I need WooCommerce?** No. The kit ships with a lightweight vanilla-JS cart that stores the
basket in the browser and opens the visitor's email app on checkout. You can point it at any form
endpoint instead.

**Does it work with Elementor Free?** Yes — Way 1 in `INSTALL.md` uses only HTML widgets.
Elementor Pro is optional (it just lets you add the CSS/JS once site-wide via Custom Code).

**Can I use the photos on client sites?** Yes. All 20 photographs are CC0/public-domain stock —
commercial use, no attribution.

**Is it responsive?** Verified at 7 widths with zero horizontal overflow, including 320 px.

**Can I change the colours?** Yes - one `:root` block at the top of `vera-kit.css` re-skins everything.

**Do you provide updates?** Replace the brand, colours and copy with your own; the structure is
theirs to keep forever (MIT licence).
